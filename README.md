# Portfolio Web App

A personal portfolio web application built with Flutter.

## Features

- Responsive design that works across devices
- Three main sections: Presentation, Projects, and Contact
- Modern UI with Material Design

## Deployment

This project is set up to deploy to GitHub Pages using a Makefile.

### Prerequisites

- Flutter SDK installed
- Git installed
- GitHub account
- Repository created on GitHub for hosting

### Deployment Steps

1. Make sure your Flutter code works locally
2. Create a repository on GitHub with the name you want to use for deployment
3. Run the deployment command: make deploy OUTPUT=Portfolio
